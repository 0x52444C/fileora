Fileora Support

Getting help

Open an issue on GitHub. Please include what step you were on (first import, picking a folder, downloading from a server, or in-game) and, if the app crashed, when that happened.

Common issues

  • "Couldn't find your data" / folder rejected on import - make sure the folder you pick is the converted data folder itself (it should directly contain a file named tokyo.wpk), not a parent folder or a zip file still waiting to be extracted.
  • Import seems slow - the data is a few gigabytes, so a full import can take a while depending on your device and connection; the progress bar and byte count are the thing to watch, not the clock. It is safe to let it run in the foreground until it finishes.
  • App closed or restarted mid-import - just reopen Fileora and try the import again; an interrupted import is always discarded automatically and never leaves a half-usable copy in place.
  • "Download from Server…" can't connect - check that the address you typed matches what the other computer's own server is printing (including the port, if any), and that both devices are on the same local network.
